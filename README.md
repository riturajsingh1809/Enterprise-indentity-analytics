# Enterprise Identity Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on analyzing enterprise identity data to understand user activity, organization and role attribution, organizational movement, historical membership, and user deprovisioning.

The project follows a complete data analytics workflow from data preparation and cleaning to Python-based analysis and Tableau dashboard visualization.

## Tools Used

* Microsoft Excel
* Python
* Pandas
* NumPy
* Jupyter Notebook
* Tableau

## Data Cleaning

The raw enterprise identity dataset was cleaned and prepared in Excel.

The cleaning process included:

* Removing duplicate records
* Handling missing values
* Standardizing text fields
* Formatting date fields
* Correcting numeric data types
* Validating user status
* Checking data quality
* Preparing an analysis-ready dataset

## Data Analysis

The analysis covers:

* Total users and organizations
* User activity
* Activity value
* Organization-wise analysis
* Role-wise analysis
* User status analysis
* Active, deprovisioned, and deleted users
* Organization movement
* Role movement
* Historical membership analysis
* Monthly activity analysis
* Data quality metrics

## Dashboard

A Tableau dashboard was created to provide an interactive view of enterprise identity data.

The dashboard includes:

* KPI cards
* User status analysis
* Organization activity
* Organization value
* Role activity
* Monthly activity trends
* Organization and role analysis
* Organization movement analysis

## Key Objective

The main objective is to maintain accurate user and organizational attribution while analyzing identity activity and ensuring that deprovisioned or deleted users are properly identified in the analytics process.

## Project Outcome

The project provides a structured and analysis-ready view of enterprise identity data and converts raw records into meaningful analytical insights through data cleaning, statistical analysis, and interactive Tableau visualization.
